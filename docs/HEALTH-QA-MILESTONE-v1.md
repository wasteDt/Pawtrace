# 健康问答阶段实施方案 v1

> 状态：已被 [关注与会话优先方案 v2](FOLLOW-CHAT-MILESTONE-v2.md) 取代，尚未按本文实施。保留本文件作为原问答方案的讨论记录。

## 1. 阶段目标

让宠物主人完成“选择宠物 → 提出健康问题 → 认证宠物医生回答 → 主人收到通知并追问/结束问题”的完整异步流程，同时支持两种入口：

- **公开健康问题**：进入健康问答广场，任何人可浏览公开内容；任意当前已认证宠物医生可回答。
- **指定医生个人提问**：从已认证宠物医生的公开资料页发起，仅问题作者和被指定医生可查看，不进入公开列表、搜索和其他人的通知。

这不是即时聊天、在线诊断或付费问诊。平台提示不能替代线下就医；紧急症状只做关键词提醒，不宣称自动诊断。

## 2. 本阶段交付与暂缓

| 本阶段必须交付 | 暂缓到后续阶段 |
| --- | --- |
| 公开问答广场、问题详情、发布页、我的问题 | 社区日常帖、点赞、收藏、关注、复杂推荐与全文搜索 |
| 可浏览的认证宠物医生列表/简要主页、向指定医生提问 | 医生排班、转诊、付费、预约与实时聊天 |
| 医生公开问题待办、收到的个人提问、回答与追问 | 医生个人病例库、学术论坛、AI 辅助诊断 |
| 图片区最多 9 张、独立视频区最多 1 个；安全上传与播放 | 视频转码流水线、复杂封面编辑与大规模媒体分发 |
| 主人主动勾选病史、按问题授权查看 | 自动共享完整宠物档案或全部病史 |
| 状态流转、标记有帮助、关闭/解决、必要的实时通知 | 回复编辑、撤销有帮助、复杂统计和多级讨论 |

这里的“暂缓”只指本阶段实施顺序，并不推翻现有 [MVP PRD](MVP-PRD-v1.md) 的长期目标。医生列表只需支撑选择和定向提问，不在本阶段引入关注系统。

## 3. 用户与页面路径

### 宠物主人

1. 顶部“健康问答”和“发布”入口不再是占位按钮，进入广场或发布页。
2. 发布页先选“公开发布”或“向指定医生提问”；个人提问必须选一位当前已认证宠物医生。没有宠物时引导先创建宠物档案。
3. 选择本人未删除的宠物，填写分类、标题、症状描述、持续时间；精神状态、饮食饮水、排泄和已采取措施为选填。
4. 图片与视频为两个独立上传区，允许同一问题同时含图片和视频。可主动勾选**该宠物**的病史；未勾选的病史不共享。发布前展示可见范围与紧急就医提示。
5. 发布后进入问题详情；在“我的问题”可分别看到公开和个人提问及当前状态。收到医生回答后可在该回答下追问、标记有帮助，并将问题标记已解决。

### 认证宠物医生

1. 专业工作台提供“公开待回答”和“收到的个人提问”；个人提问仅被指定医生可见。
2. 问题详情可看主人主动附带的病史，不能读取该宠物未共享的其他病史或完整健康档案。
3. 医生回答后，问题由待回答转为已回答；主人追问后，原回答医生可继续回复。个人提问的回答入口只对指定医生开放。
4. 认证被撤销后，不能再查看专业限定病史、个人提问或提交医生回复；既有公开回答保留，但不再显示为当前有效认证身份。

### 医生助理与普通浏览者

- 当前已认证医生助理可读**公开问题中主人主动附带的病史**，但不能发布正式医生回答，也不能成为个人提问对象或查看个人提问。
- 游客与普通登录用户可浏览公开问题及公开回答，但看不到附带病史、宠物完整档案、私密媒体或任何个人提问。

## 4. 页面与关键状态

| 页面 | 最小内容及操作 | 空态/异常态 |
| --- | --- | --- |
| 健康问答广场 | 公开问题卡片、状态/宠物种类/分类筛选、进入详情、“我要提问” | 无问题、加载失败、已删除问题不可见 |
| 发布问题 | 模式、宠物、分类、必填症状、图片区、视频区、病史勾选、隐私与就医提示 | 无宠物、医生身份失效、上传失败、重复提交 |
| 问题详情 | 公开/个人可见标识、宠物公开摘要、媒体、按权限裁剪的病史、医生回答与追问、状态操作 | 无权限统一不泄露私密内容；已关闭只读 |
| 我的问题 | 本人问题列表、公开/个人筛选、未回答/已回答/已解决/已关闭状态 | 无问题引导提问 |
| 医生列表/简要主页 | 展示名、机构、擅长领域、当前认证标识、“向医生提问” | 医生认证失效时不能新建定向问题 |
| 医生问答工作台 | 公开待回答、个人待办、我的回答；进入详情回复 | 无待办；身份失效后不可继续访问 |

页面不根据按钮是否显示来决定权限；服务端必须重新校验当前身份、问题模式、所属关系和状态。详情接口返回 `permissions`，供前端决定显示哪些操作。

## 5. 数据和接口范围

按 [数据库设计](DATABASE-DESIGN-v1.md) 的 `content_items`、`health_questions`、`question_replies`、`question_history_shares`、媒体关联模型落地本阶段所需字段。公开与个人提问使用**同一个问题模型**，由 `mode=PUBLIC_FORUM|DIRECT_DOCTOR` 区分；不把个人提问做成公开帖子，也不把宠物病史复制为新的“医生病例”。

| 数据 | 必要字段/关系与规则 |
| --- | --- |
| 问题 | 作者、宠物、分类、模式、指定医生、标题/症状、结构化补充信息、状态、创建/关闭/解决时间；个人模式必须指定当前有效医生 |
| 回答与追问 | 问题、作者、父回复、服务端判定的角色、正文、发布时间；首版最多一层追问 |
| 病史共享 | 问题与主人主动选定的病史 ID 关联；提交时校验病史属于所选宠物与当前作者；详情按当前权限取数 |
| 媒体 | 上传者、用途、种类、存储键、文件元数据、公开/私密可见性及与问题/回复的关联；**文件访问也必须鉴权** |
| 分类 | 本阶段提供固定的健康问题分类种子数据，不做管理后台分类配置界面 |
| 通知 | 新个人提问通知指定医生；医生回答通知作者；主人追问通知对应回答医生；使用现有收件箱持久化与 SSE 实时推送 |

本阶段拟实现的主要接口沿用 [API 设计](API-DESIGN-v1.md) 的命名：

- `GET/POST /api/v1/questions`、`GET /api/v1/questions/:questionId`、`GET /api/v1/me/questions`。
- `GET /api/v1/professional/questions/open|direct|answered`、`GET /api/v1/professionals`、`GET /api/v1/professionals/:userId`。
- `POST /api/v1/questions/:questionId/replies`、`PUT /api/v1/questions/:questionId/helpful-reply`、`POST /api/v1/questions/:questionId/resolve|close`。
- 通用媒体上传与受控访问接口；认证材料接口继续保持独立用途和私密访问，不因问答媒体改造而公开。

公开列表只返回安全摘要，不返回病史或完整宠物档案。个人问题在无权访问时返回不泄露存在性的错误；不能通过列表、计数、媒体地址或通知内容旁路获取。创建问题、回复和状态操作使用事务校验前置状态；重复提交需有幂等保护。

## 6. 媒体与医疗隐私约束

- 最多 9 张图片，每张不超过 10 MB；另可上传 1 个视频，不超过 100 MB、3 分钟。图片和视频分别选择、校验、展示；不使用单个混合控件。
- 服务端检查真实文件类型及视频时长，限制文件大小与可接受格式；客户端预览与进度不能替代服务端校验。具体格式白名单在实现时与浏览器兼容性一并验证。
- 个人提问的全部媒体只对作者和指定医生开放；公开问题的公开媒体可供浏览者访问，但所附病史及其附件仍按病史权限单独鉴权。
- 病史默认私密。公开问题的共享病史仅作者、当前认证医生和当前认证助理可看；个人提问共享病史仅作者与指定医生可看。取消认证后权限立即失效。
- 不在日志、通知正文、公开搜索结果中写入病史正文、个人提问内容或私密媒体地址。
- 页面固定提示平台交流不能代替诊疗；命中呼吸困难、抽搐、中毒等关键词时再突出线下急诊提醒，但仍允许发布问题。

## 7. 交付顺序

1. 数据迁移、分类种子、媒体安全上传/访问；先验证旧认证材料与现有宠物档案不受影响。
2. 公开问题的发布、广场、详情与按权限共享病史。
3. 医生列表/简要主页、个人提问、指定医生待办与私密访问。
4. 医生回答、主人追问、有帮助、解决/关闭状态及双端实时通知。
5. 联调页面空态、错误态和权限边界，补自动化测试与人工验收脚本。

每一步完成后都能独立构建和迁移，但以整条问答闭环通过验收作为本阶段完成条件；不把“页面可点击”视为功能完成。

## 8. 验收清单

1. 主人有宠物时能提交包含文字、图片和视频的公开问题；问题出现在公开广场，病史默认不共享。
2. 勾选病史后，作者、当前认证医生和助理能读取所选病史；普通用户、游客和被撤销认证者不能读取；未勾选病史任何专业用户都不能读取。
3. 主人能从当前已认证医生主页发起个人提问；除作者和指定医生外，其他医生、助理、管理员普通列表和游客均不能访问问题、附件或存在性信息。
4. 只有当前认证医生能回答公开问题；个人问题只能由指定医生回答。主人和助理伪造请求也被后端拒绝。
5. 回答、追问、标记有帮助、解决和关闭按允许的状态流转；重复点击/并发请求不产生多次首答、矛盾状态或重复通知。
6. 医生收到个人提问、主人收到医生回答、对应医生收到主人追问时，在线收件箱实时出现消息；断线重连后仍能从列表读取。
7. 图片与视频可以同时存在且分区展示；超量、超大、类型不符、时长超限和越权访问都给出明确错误。
8. 宠物或医生身份在发布前发生变化、问答过程中医生身份被撤销、问题被关闭后继续回复等竞争场景均由服务端正确拒绝。
9. 未登录用户可浏览公开问题，但不能发布、回复或读取任何私密病史与个人提问。

## 9. 需要你重点确认的取舍

- 本阶段先不做公开问题的点赞、收藏和普通评论，只保留医生回答、主人追问及“有帮助”。
- 本阶段做**简要医生主页**作为个人提问入口，不做关注系统或完整社交主页。
- 视频按既定上限纳入本阶段；实现会涉及更完整的媒体校验和受控访问，工作量明显高于纯文字问答。
- 被指定医生若认证被撤销，原个人提问暂时保持私密且无人可接替回答；作者可查看并关闭，暂不提供转诊或改派医生。
