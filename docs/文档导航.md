# Pawtrace 文档导航

文档按“现行决策 → 已实现代码 → 初版蓝图”阅读。初版蓝图用于了解完整产品目标，不代表全部功能已经上线；与后续决策冲突时，以现行专题文档及代码为准。

| 主题 | 文档 | 适合何时阅读 |
| --- | --- | --- |
| 现行阶段 | [关注与聊天](关注与聊天.md) | 查看已确认的关注、会话权限、实时消息及后续医生提问路线 |
| 已实现系统 | [后端实现导读](后端实现导读.md) | 理解当前业务流程、技术栈、代码位置和实际接口 |
| 管理与消息 | [管理端与通知](管理端与通知.md) | 理解管理后台、身份升级/撤销和双端工作通知 |
| 产品全貌 | [产品需求](产品需求.md) | 查看角色、长期功能范围及初版需求；部分旧交互已被现行阶段方案覆盖 |
| 页面体验 | [页面交互](页面交互.md) | 查看初版页面路径与低保真说明，具体聊天行为以现行阶段方案为准 |
| 视觉规范 | [设计令牌](设计令牌.md) | 查看颜色、字体、间距、控件和无障碍约定 |
| 规划模型 | [数据库设计](数据库设计.md) | 查看初版完整数据蓝图；实际表以 Prisma 模型和迁移为准 |
| 规划接口 | [接口设计](接口设计.md) | 查看初版 REST API 蓝图；实际接口以路由代码和后端导读为准 |
