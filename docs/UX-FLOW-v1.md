# Pawtrace 第一版页面流程与低保真交互说明

> 文档状态：已确认  
> 版本：v0.1  
> 更新日期：2026-10-08  
> 前置文档：[MVP-PRD-v1.md](./MVP-PRD-v1.md)  
> 适用范围：第一版响应式 Web 产品

## 1. 文档目标

本文用于确认第一版页面结构、导航方式、关键用户流程和低保真页面布局，不定义最终颜色、字体、插画与精细视觉效果。

设计目标：

- 手机端优先，同时适配桌面浏览器。
- 默认身份是宠物主人，专业身份作为认证后的附加能力。
- 健康问答、专业病例和学术论坛在信息层级上清晰分开。
- 医疗相关操作始终展示身份、隐私和线下就医提示。
- 尽量复用页面和组件，减少第一版实现成本。

## 2. 全局导航

### 2.1 桌面端导航

```text
┌──────────────────────────────────────────────────────────────┐
│ Pawtrace  首页  健康问答  [学术论坛*]  搜索  ＋发布          │
│                                      通知  头像/我的         │
└──────────────────────────────────────────────────────────────┘

* 学术论坛仅认证宠物医生和医生助理显示。
```

- Logo 点击返回首页。
- “发布”点击后，根据权限展示可发布类型。
- 认证专业用户的头像菜单中增加“专业工作台”。
- 未登录用户点击互动或发布功能时，跳转手机号登录页。

### 2.2 移动端导航

```text
┌─────────────────────────────┐
│ 页面标题          搜索  通知 │
│                             │
│          页面内容           │
│                             │
├─────────────────────────────┤
│ 首页  问答  ＋发布  通知  我的│
└─────────────────────────────┘
```

- 底部导航固定显示：首页、问答、发布、通知、我的。
- 学术论坛和专业工作台放在“我的”页面专业功能区。
- 点击中间发布按钮弹出发布类型选择面板。

### 2.3 发布类型选择

普通用户：

- 发布宠物日常。
- 发布养宠知识。
- 发布公开健康问题。

认证医生助理额外增加：

- 创建专业病例。
- 发布学术讨论。

认证宠物医生额外增加：

- 创建专业病例。
- 发布学术讨论。

医生回答不作为独立发布入口，只能从问题详情页进入。

## 4. 核心流程

### 4.1 手机号登录与首次使用

```text
访问需登录功能
  ↓
手机号登录页
  ↓ 获取模拟验证码
输入验证码并提交
  ├─ 已注册 → 返回原目标页面
  └─ 新用户 → 首次资料完善 → 返回原目标页面/首页
```

关键规则：

- 获取验证码后直接在表单下方显示模拟验证码。
- 登录页保留用户进入登录前的目标地址。
- 新用户只填写头像和昵称，不选择身份。
- 完成后自动拥有宠物主人权限。

### 4.2 创建宠物与记录病史

```text
我的 → 我的宠物 → 新建宠物 → 保存 → 宠物详情
                                      ↓
                               新增病史 → 保存
```

- 创建健康问题前没有宠物时，引导用户先创建宠物。
- 病史默认私密，不自动出现在公开主页。
- 健康问题发布页只允许主动勾选需要提供给医生的病史。

### 4.3 发布公开健康问题

```text
健康问答/发布按钮
  ↓
选择“公开健康问题”
  ↓
选择宠物 → 填写症状 → 上传图片或视频 → 可选附带病史
  ↓
确认隐私和就医提示 → 发布成功 → 公开问题详情
  ↓
医生回答 → 主人收到通知 → 主人追问/标记有帮助 → 已解决
```

发布前检查：

- 必须有关联宠物、标题、症状、持续时间和问题分类。
- 图片和视频使用独立上传分区；同一问题可以同时包含最多 9 张图片和 1 个视频。
- 命中紧急关键词时，先弹出立即线下就医提示；用户确认后仍可保存问题。
- 附带病史时明确提示其专业可见范围。公开问题中，病史附件仅问题作者、认证宠物医生和认证医生助理可见，不向普通浏览者展示。

### 4.4 向指定医生个人提问

```text
医生公开主页 → 向医生提问
  ↓
选择宠物 → 填写问题 → 可选附带病史 → 提交
  ↓
私密问题详情
  ↓
医生收到通知 → 回答/关闭 → 主人追问或结束
```

- 入口仅存在于认证宠物医生主页。
- 医生助理主页不显示“向医生提问”。
- 提问不进入公开信息流，仅双方可见。
- 第一版不收费，也不展示承诺回复时间。

### 4.5 专业身份认证

```text
我的 → 专业身份认证
  ↓
选择宠物医生 / 医生助理
  ↓
填写资料并上传对应证明 → 提交 → 审核中
  ├─ 通过 → 解锁专业能力
  └─ 驳回 → 查看原因 → 修改并重新提交
```

- 宠物医生必须上传执业兽医资格证材料。
- 医生助理必须上传相关专业学历证明。
- 审核中不允许切换申请类型。
- 医生助理升级宠物医生时，发起新的认证申请；原身份在新申请审核期间继续有效。

### 4.6 病例库与学术讨论

```text
专业工作台 → 病例库 → 新建病例 → 保存私密病例
                                      ↓
                              发布为学术讨论
                                      ↓
                         匿名化检查 → 预览 → 发布
```

- 病例始终保留在创建者的私密病例库。
- 发布讨论时复制允许公开的内容，不改变原始病例的私密性。
- 发布确认页要求勾选“已移除可识别个人身份的信息”。
- 学术论坛只允许认证宠物医生和医生助理查看及互动。

### 4.7 关注流程

```text
用户公开主页/内容作者区 → 关注
  ↓
首页“关注” → 查看已关注用户的最新公开内容
  ↓
我的 → 关注与粉丝 → 取消关注/访问主页
```

- 不能关注自己。
- 被禁用或注销的账号不再出现在关注信息流。
- 第一版不发送“有人关注你”的通知。

### 4.8 管理员审核专业身份

```text
后台登录 → 待审核列表 → 查看申请与证明材料
  ├─ 通过 → 记录审核人和时间 → 通知申请人
  └─ 驳回 → 填写原因 → 通知申请人
```

- 宠物医生与医生助理使用不同审核筛选项。
- 审核结果必须填写备注；驳回原因对申请人可见。
- 已通过身份的撤销不在普通审核按钮中完成，需进入用户详情并记录原因。

│                                │

```text

│ Pawtrace              [搜索] [通知] [头像]  │

│ 当前状态       │ 审核记录                    │
│               │ [驳回] [通过]               │
└───────────────┴──────────────────────────────┘
```

移动端后台仅保证基础可用，后台主要按桌面端设计。

## 6. 通用组件

第一版建议建立以下复用组件：

- 顶部导航、移动底部导航、侧边菜单。
- 用户头像、认证身份徽章、关注按钮。
- 内容卡片、健康问题卡片、学术讨论卡片、病例卡片。
- 图片宫格、视频播放器、媒体上传器。
- 评论与回复列表。
- 宠物选择器、病史选择器、医生选择器。
- 分类标签、状态标签和筛选栏。
- 医疗免责声明、紧急就医提示和隐私提示。
- 空状态、加载骨架、错误状态、无权限状态。
- 确认弹窗、抽屉、消息提示和分页组件。

## 7. 全局状态与异常处理

每个主要页面都要覆盖以下状态：

- 首次加载：显示骨架屏或加载状态。
- 空数据：解释为什么为空，并提供主要行动按钮。
- 请求失败：保留页面结构并提供重试。
- 无权限：说明所需身份并提供登录或认证入口。
- 内容不存在：显示返回上一级入口。
- 内容已下架：作者可见原因，其他用户只看到不可访问提示。
- 账号被禁用：阻止继续操作，并提供申诉或联系说明。
- 上传失败：保留已成功文件，允许单个文件重试。
- 表单重复提交：提交期间禁用按钮，后端保证幂等或去重。

## 8. 响应式规则

- `< 768px`：移动布局，单列内容，使用底部导航和全屏表单。
- `768px–1199px`：平板布局，主要内容单列或窄双栏。
- `≥ 1200px`：桌面布局，信息流页面可使用主内容加辅助侧栏。
- 核心正文建议最大宽度 760px，避免医疗信息行宽过长。
- 表格在窄屏下切换为卡片列表，不进行强制横向压缩。
- 触控目标最小建议 44×44px。

## 9. 无障碍与易用性

- 表单字段必须有可见标签，不能只依赖占位文本。
- 错误提示同时使用文字和图标，不只依赖颜色。
- 图片提供替代文本能力；视频提供封面和播放控制。
- 键盘可以访问导航、表单和弹窗。
- 医疗警告保持足够对比度并使用清晰直白的文案。
- 删除、关闭问题、撤销认证等重要操作必须二次确认。

## 10. 已确认的交互决策

1. 公开健康问题附带的宠物病史仅问题作者、认证宠物医生和认证医生助理可查看，普通浏览者不可见。
2. 指定医生的个人提问完全私密，仅主人和被指定医生可见。
3. 同一内容支持最多 9 张图片和 1 个视频，图片与视频使用独立上传及展示分区，不使用混合上传控件。视频上限暂定 3 分钟、100 MB。
4. 专业工作台名称统一使用“专业工作台”，医生助理和宠物医生共用；医生专属模块按权限隐藏。
5. 学术论坛无权限时显示认证引导页，不展示任何论坛内容预览。
6. 手机端将学术论坛入口放在“我的/专业功能”，不占用底部主导航。
